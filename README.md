# Morrow Motor Co.

A responsive curated-car inventory built with React, TypeScript, and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```

The inventory uses local sample vehicle data in `src/CarListings.tsx`. Vehicle photography is loaded from Unsplash image URLs; replace the sample listings and image URLs with your own catalog before publishing.

Search by make, model, trim, or year. Filter by make, body style, year range, and maximum price; sort by price or mileage; save listings; switch between grid and list layouts; and open a vehicle to send a sample inquiry.
